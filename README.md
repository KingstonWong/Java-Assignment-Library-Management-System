#CLI #Java CLI Development #Degree

In this assignment, students are required to develop a software application and apply programming concepts to solve practical problems.

For my assignment, I developed a command-line based Library Management System using Java. The system integrates with an ASP.NET REST API to communicate with the database and perform various library management operations. Unlike a graphical user interface (GUI) application, users interact with the system through a command-line interface (CLI) by entering commands to access different functions.

The system consists of several modules, including Dashboard, Member Management, Book Management, Loan Management, Pending Requests, and Fine Management.

One of the key features is the online book request module, which allows members to request books through the system. The request remains in a pending state until it is reviewed and approved by the administrator. Once approved, the system automatically sends an email notification to the member, informing them that the requested book is ready for pickup.

The system also includes an automated fine calculation feature. When a member returns a book, the system checks the return date against the due date and automatically determines whether an overdue fine should be imposed.

The Dashboard module provides useful insights by displaying the Top 5 Most Borrowed Books and a list of Overdue Borrowing Records. These statistics help library administrators monitor book circulation and identify overdue loans efficiently.

The application communicates with an ASP.NET REST API to handle data processing and database operations, enabling efficient management of library records and transactions.

The project is developed using the following technologies:

* Python
* C#
* REST APIs
* Entity Framework Core
* SQL Server
  
These technologies are integrated to create a secure and efficient library management system that improves book circulation, member services, and overall library administration through a command-line environment.
